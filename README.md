# Парсер и отправка контента с сайта Wallhaven

Это парсер, он может сохранять картинки, в папку src/{rating}/, так же столько сколько захотите, он полностью логгирует свою работу.
Также он может отправлять картинки в телеграм группу с топиками в разные топики. 

Как установить?

Для начала, нужно иметь python 3.12.3, GIT.
Надо склонировать репозиторий в удобное место

```bash
  git clone https://github.com/L1ghtdevelop/wallhaven_parser
  cd wallhaven_parser
```
После этого нужно создать виртуальное окружение для этого:
```bash
  python -m venv .venv
  source .venv/bin/acitvate
```
Или если у вас линукс:
```bash
  python3 -m venv .venv
  source .venv/bin/acitvate
```
После этого надо загрузить все зависимости для этого надо:
```bash
  pip install -r requirements.txt
```
После этого создатите в главной директории файл .env 
Туда нужно написать такие токены и id как:
**API_TOKEN** - Токен wallhaven дается при регистрации на странице аккаунта
**BOT_TOKEN** - Токен телеграм бота, который дает @BotFather
**GROUP_ID** - id group который может дать бот для этого @idbot

После этих настроек с включенным venv Запускаете 
```bash
  python main.py
```
Или если у вас линукс 
```bash
  python3 main.py
```
После этого вы увидите
```bash
Выберете возрастную категорию: sfw/sketchy/nsfw
```
Вводите точно как написано одну из трех или двух категорий если нету api wallhaven, то nsfw недоступен. Но регистр не учитывается
После этого будет 
```bash
Вы хотите самому выполнить или отдать в расписание? myself/shedule
```
Вводите или расписание или самому сделать сейчас и настроить, если выбираете **shedule** то будет пустой экран и он будет ждать 10 часов утра и 9 часов вечера для отправки изображений которые
он запарсит на час раннее, только это 20 изображений, если же вы выбрали **myself**, то увидите
```bash
Что вы хотите сделать? parse/send
```
Он спрашивает, что вы хотите сделать отправить картинки из директории категории, которую выбрали ранее.
Или запарсить изображения из выбранной категории
При **parse** он запарсит одну страницу и сохранит в директорию src/{rating} и при завершении отправит **Success**
При **send** он отправит эти картинки в группу которая указана в **.env**
